# ARIMA и Random Forest: проверка и согласованный эксперимент

Исходная реализация Дмитрия Маслова от 02.11.2026 сохранена без изменения в `archive/`. Для итогового сравнения создан исправленный `run_arima_rf_experiment.py` на общем дневном ряду Dukascopy и одинаковых тестовых датах с Naive и MLP.

## Почему первый результат Random Forest нельзя было использовать

В исходном скрипте обучающая цель — `price[t]`, а среди признаков есть `ma_3[t]`, `lag_1[t]` и `lag_2[t]`. Поэтому **истинная цена в точности восстанавливается по входам**:

`price[t] = 3 * ma_3[t] - lag_1[t] - lag_2[t]`.

Это прямая утечка: признаки будущего дня не могли быть известны в момент формирования прогноза. Кроме того, исходная версия:
- искала CSV в корне вместо `data/raw/` и не запускалась после клонирования репозитория;
- использовала календарный D1 из 312 свечей UTC вместо 258 согласованных торговых сессий;
- использовала последние 30 наблюдений как тест вместо 47 общих дат;
- считала RF на 30 фактических днях теста, тогда как ARIMA — на прогнозе только одной исходной даты;
- сохраняла четыре прогноза, а для общего сравнения нужно 2 модели × 2 горизонта × 47 дат = 188;
- сравнивала несопоставимые MAE.

Поэтому прошлое заявление об улучшении RF над Naive **не подтверждается корректным экспериментом**.

## Исправленная схема

- Цель: XAU/USD Bid Close от Dukascopy; 258 сессий 28.10.2025–27.10.2026.
- Общий замороженный тест: 47 исходных дат **17.08–20.10.2026**, последний известный Close на дату обучения — 14.08.2026.
- Цели прогнозов: через **1 и 5 торговых сессий**. Для всех четырёх моделей одинаковые исходные и целевые даты.
- Четыре расширяющихся окна до итогового теста для выбора настроек по средней MAE.
- Random Forest: 10 текущих и исторических признаков из базового проекта; в каждый момент используются только значения, уже известные на завершении сессии t. Цель RF — `log(C[t+h]/C[t])`, затем прогноз возвращается в USD. Отдельная модель на каждый горизонт. Случайное зерно 42.
- ARIMA: рассматриваются порядки (0,1,0), (1,1,0), (0,1,1), (1,1,1). По тестовым датам обновляется только состояние ARIMA фактически завершёнными свечами методом `extend`; параметры модели **не подбираются и не переобучаются** на тесте.
- Никакие тестовые метрики не используются для отбора моделей. Данные внешних макроиндикаторов Алексея не включены, поскольку их историческая доступность ещё не подтверждена.

## Метрики на одинаковых 47 датах

| Модель | Горизонт | MAE, USD | RMSE, USD | sMAPE, % | Точность направления, % |
|---|---:|---:|---:|---:|---:|
| Naive | 1 | 47,57 | 63,75 | 1,10 | 0,00 |
| ARIMA | 1 | 47,57 | 63,75 | 1,10 | 0,00 |
| MLP | 1 | 47,50 | 63,01 | 1,09 | 51,06 |
| Random Forest | 1 | 49,46 | 65,32 | 1,14 | 44,68 |
| Naive | 5 | 93,96 | 123,08 | 2,16 | 0,00 |
| ARIMA | 5 | 93,96 | 123,08 | 2,16 | 0,00 |
| MLP | 5 | 112,38 | 143,06 | 2,59 | 34,04 |
| Random Forest | 5 | 101,58 | 133,48 | 2,34 | 46,81 |

Точные показатели сохранены в `results/arima_rf/comparison.csv`. Для однодневного горизонта RF хуже Naive по MAE на **3,99%**, для пятидневного — на **8,11%**.

На четырёх валидационных окнах ARIMA выбрала порядок **(0,1,0)** для обоих горизонтов. При отсутствии дрейфа это случайное блуждание: прогноз равен последнему наблюдённому Close. Поэтому ARIMA и Naive в итоговом тесте дают одинаковые результаты — без ошибки в коде.

Random Forest выбрал в обоих горизонтах 120 деревьев, `max_depth=4`, `min_samples_leaf=3`, `max_features=0.8`. Это итог выбора **на валидации**, а не подгонка по тесту.

Устойчивость: три последовательных тестовых блока находятся в `results/arima_rf/temporal_blocks.csv`. Динамика ошибок заметно различается по частям теста; один лучший результат в небольшом блоке не доказывает устойчивого превосходства. Замеры обучения и предсказания в текущем окружении — `results/arima_rf/timings.csv`. Точные времена зависят от компьютера.

## Что запускать

Из корня проекта после установки `requirements-mlp.txt`:

```powershell
python -m pytest -q
python run_daily_baseline.py
python run_mlp_experiment.py
python run_arima_rf_experiment.py
```

Скрипт сохраняет:
- `arima_rf_predictions.csv` и `results/arima_rf/predictions.csv` — **188 прогнозов** ARIMA/RF;
- `results/arima_rf/all_four_predictions.csv` — **376 прогнозов четырёх моделей**;
- `results/arima_rf/comparison.csv`, `validation.csv`, `temporal_blocks.csv`, `timings.csv`, `metadata.json`;
- `results/arima_rf/comparison.png` — прогнозы и абсолютные ошибки.

## Ограничения и вывод

По фиксированному годовому эксперименту сложность моделей сама по себе не гарантирует уменьшения MAE. MLP имеет разницу с Naive всего ~0,13% на одном дне, которую нельзя считать убедительным превосходством; на пяти днях лучшим по MAE остаётся Naive (и эквивалентная ему ARIMA (0,1,0)).

Это **сравнение только на одном годовом периоде**, 47 тесно связанных тестовых датах с пересекающимися пятидневными горизонтами. Нельзя утверждать статистическую значимость разниц или переносить результат на весь рынок. Историческое точное время окончания девяти сокращённых сессий также остаётся оговоркой, отражённой в `HOLIDAY_SESSION_AUDIT.md`.

Первоначальный код и CSV Дмитрия оставлены в `archive/` как история работы и не используются для итоговых выводов.
