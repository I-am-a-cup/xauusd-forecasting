# Как работаем с репозиторием

Проект ведём на русском: README, задачи, пояснения и сообщения коммитов. Имена Python-функций, файлов, библиотек и столбцов CSV оставляем на английском, чтобы не ломать код.

Каждый работает в своей ветке, например `feature/data-cleaning` или `feature/arima`. В `main` объединяем изменения после проверки другим участником.

Перед работой обновите `main` и создайте ветку:

```powershell
git checkout main
git pull origin main
git checkout -b feature/data-cleaning
```

После изменений:

```powershell
python -m pytest -q
git add .
git commit -m "Добавить очистку котировок XAU/USD"
git push -u origin feature/data-cleaning
```

Затем создайте Pull Request в GitHub.

## Общие правила

- Сначала прочитайте [EXPERIMENT.md](EXPERIMENT.md) и [DATA.md](DATA.md). Торговый календарь ещё не согласован.
- Используйте один формат прогнозов: `origin_date,target_date,horizon,model,y_pred`.
- Не подбирайте параметры по тесту и не используйте будущие цены при обучении.
- Сохраняйте параметры, время работы модели, случайное зерно и версии зависимостей.
- К своим изменениям добавляйте тесты или понятный способ проверки.

Для итогового README каждый готовит результаты и краткое объяснение своей части. На защите участвуют все четверо, поэтому перед сдачей проверим общий запуск вместе.
