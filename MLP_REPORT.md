Часть Андрея Зуева, практики 8–9. Расчёт выполнен 2 ноября 2026 года по [общему протоколу](EXPERIMENT_PROTOCOL.md), на версии данных из коммита `0e41f57`. Это сравнение **MLP и Naive**; результаты ARIMA/RF сюда не входят.

Практика задаёт требования всей группе, а команда поручила Андрею нейросетевой метод, устойчивость и вычислительные затраты. Ниже — выполненные пункты в пределах этой части.

Четыре метода в одной сводной таблице и общая десятиминутная презентация относятся ко всей группе. Здесь реализована и оценена её нейросетевая составляющая. Исследование иных нейросетей или вымышленных рыночных сценариев не входит в эту работу.

## Воспроизведение

Из корня проекта, Python 3.11.7:

```powershell
python -m pip install -r requirements-mlp.txt
python -m pytest -q
python run_mlp_experiment.py
```

Загрузка из интернета при расчёте не нужна. Скрипт использует уже сохранённые дневные котировки и проверяет совпадение признаков с опубликованным `xauusd_daily_model_ready.csv`. При изменении календаря сначала нужно пересоздать оба файла через `run_daily_baseline.py`, затем повторить сравнение всех моделей.

## Методика

- 258 сессий Dukascopy; 196 общих обучающих примеров; 47 общих дат прогноза 17.08–20.10.2026 для обоих горизонтов. Последняя известная цена обучения — 14.08.2026.
- Ровно 10 признаков `src.daily_features.FEATURES`: текущая Close, три лага Close, две доходности, относительный диапазон, скользящие среднее и волатильность, день недели. Внешние индексы и будущие цели не входят в X.
- Две независимые небольшие сети предсказывают `log(C[t+h]/C[t])`. Возврат к цене: `C[t] * exp(prediction)`. Это сохраняет положительность цены и позволяет моделировать изменение относительно последней известной цены. Ценовые MAE при подборе рассчитываются после обратного преобразования.
- Признаки и целевая логарифмическая доходность стандартизируются только на train каждого окна: `Pipeline(StandardScaler, MLPRegressor)` внутри `TransformedTargetRegressor`.
- Шесть вариантов: скрытые слои `(4,)`, `(8,)`, `(8,4)` × L2 `alpha=1` или `10`. Общие параметры: `tanh`, L-BFGS, `max_iter=2000`, `max_fun=50000`, `tol=1e-6`. Предобученных моделей нет. L-BFGS подходит для небольшого набора без минибатчей; случайная внутренняя валидация отключена.
- Четыре расширяющихся окна, как у общего baseline: начальная история 105 сессий, окна 25, шаг 25. В каждом окне 20 общих исходных дат. Выбор по среднему MAE четырёх окон, отдельно для каждого горизонта; при равенстве — первый кандидат. Сетка и основное зерно 42 заданы до оценки на тесте.
- Для обоих горизонтов последний обучающий origin не позже `last_known_index-5`. Пять исходных строк перед валидацией исключаются из обучающих примеров; каждая обучающая цель известна до начала проверки. Дополнительный пятидневный разрыв после последней известной цены протокол не вводит.
- На итоговом тесте веса и масштабы заморожены. Новые наблюдённые на дату t OHLC разрешены для расчёта признаков; будущие цены в прогноз не поступают.

Выбраны `(8,)`, `alpha=10` для h=1 (97 параметров), `(8,4)`, `alpha=10` для h=5 (129 параметров). Средний MAE на валидации: 53,49 и 108,72 USD. Все 58 обучений (48 при подборе и 10 при проверке инициализаций) завершились без предупреждений о сходимости.

Описание параметров и оптимизатора: [официальная документация MLPRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.neural_network.MLPRegressor.html).

## Итоговый тест, фиксированное зерно 42

| Модель | Горизонт | n | MAE, USD | RMSE, USD | sMAPE, % | Направление, % |
|---|---:|---:|---:|---:|---:|---:|
| Naive | 1 | 47 | 47,57 | 63,75 | 1,097 | 0,00 |
| MLP | 1 | 47 | 47,50 | 63,01 | 1,094 | 51,06 |
| Naive | 5 | 47 | 93,96 | 123,08 | 2,165 | 0,00 |
| MLP | 5 | 47 | 112,38 | 143,06 | 2,590 | 34,04 |

На одном дне выигрыш MLP по MAE — всего **0,0635 USD, или 0,13%**. Это практически равный результат, а не доказательство устойчивого превосходства нейросети. На пяти днях MAE MLP **выше на 18,41 USD, или 19,60%**. У MLP увеличение горизонта повышает MAE примерно в 2,37 раза; у Naive — в 1,98 раза.

Точность направления Naive равна нулю из-за `sign(0)=0`: она прогнозирует отсутствие изменения, фактические изменения ненулевые. Поэтому сравнивать эти 0% с MLP как самостоятельное доказательство преимущества нельзя.

## Устойчивость

Пять заранее заданных инициализаций: 42, 17, 73, 101, 137. Для них используются одни выбранные по валидации параметры; **лучшее зерно по тесту не выбирается**. Основной результат всегда относится к 42.

| Горизонт | Среднее MAE | Стандартное отклонение MAE (ddof=1) | Минимум–максимум |
|---|---:|---:|---:|
| 1 | 47,4623 | 0,0371 | 47,4337–47,5033 |
| 5 | 112,4195 | 0,0286 | 112,3772–112,4566 |

Чувствительность к инициализации мала, но это не означает устойчивого выигрыша по времени. Тест дополнительно разделён на три последовательных блока по 16, 16 и 15 дат:

| Даты origin | h=1 Naive / MLP | h=5 Naive / MLP |
|---|---:|---:|
| 17.08–07.09 | 65,04 / 65,14 | 136,36 / 148,75 |
| 08.09–29.09 | 47,33 / 45,81 | 85,83 / 104,63 |
| 30.09–20.10 | 29,17 / 30,50 | 57,41 / 81,84 |

На h=1 сеть выигрывает только в среднем блоке; на h=5 проигрывает во всех трёх. Средняя прогнозируемая доходность на h=5 составляет +1,00%, фактическая на тесте — −1,03%. Это показывает положительное смещение прогноза на данном участке. Малый объём данных, регуляризация и изменение динамики рынка — возможные объяснения, но их причинная роль отдельными опытами не доказана.

## Вычислительные затраты

Один запуск на CPU Windows, Python 3.11.7, один поток численных библиотек. Точное описание среды и все измерения сохранены в `results/mlp/metadata.json` и `timings.csv`.

| Этап | Время |
|---|---:|
| Подготовка таблиц признаков для четырёх окон и финального обучения | 0,052 с |
| Подбор двух горизонтов: 48 обучений | 4,837 с |
| Финальное обучение h=1, seed=42 | 0,032 с |
| Финальное обучение h=5, seed=42 | 0,087 с |
| Прогноз 47 дат h=1 / h=5 | 0,000955 / 0,001300 с |
| Весь запуск, включая дополнительные зерна, запись и график | 6,952 с |

Это разовые измерения, без учёта импорта библиотек до входа в `run`; они зависят от компьютера и нагрузки. Время Naive также записано, но его функция включает формирование таблицы, а таймер прогноза MLP — извлечение X, transform и численный прогноз. Поэтому отношения скоростей по этим таймерам не рассчитываем. Сравнение с ARIMA/RF потребует общего измерителя капитана.

## Файлы результатов

- `results/mlp/predictions.csv` — **ровно пять согласованных столбцов**, 94 прогноза основного зерна 42. Капитан добавляет факты общим `attach_actuals` и сравнивает с ARIMA/RF на тех же датах.
- `comparison.csv` — сравнение с Naive всеми четырьмя метриками, абсолютное и относительное изменение MAE.
- `validation.csv` — все 48 результатов подбора, без итогового теста.
- `seed_metrics.csv`, `seed_predictions.csv` — чувствительность к инициализации.
- `temporal_blocks.csv`, `largest_errors.csv`, `forecast_errors.png` — анализ ошибок по времени и график.
- `metadata.json`, `timings.csv` — параметры, предупреждения, версии, SHA-256 данных/протокола и время.
- `presentation/mlp_speaker_notes.md` — содержание двух слайдов, речь и вопросы для защиты.

Для интеграции из Python доступна `src.models.mlp.predict_mlp(prices, origins, last_known_index=..., configs={1: ..., 5: ...})`. Передавать выбранные конфигурации из `metadata.json`; значения по умолчанию предназначены для проверки контракта. Функция возвращает DataFrame общего формата, не подбирая настройки по переданным датам теста.

## Проверки и ограничения

Добавлены проверки совпадения дат с Naive, недоступности будущих цен для первого прогноза, обучения масштабов только на train, отсутствия изменения весов при predict, известных целей во всех четырёх окнах и отказа обучаться на строках test. Всего проходят 34 теста.

Девять сокращённых сессий всё ещё требуют подтверждения Алексеем; при изменении календаря эти результаты нужно пересчитать. На 47 датах, с перекрывающимися целями h=5, статистическую значимость различий не утверждаем. Дополнительные 168 внешних колонок не подключены, поскольку время доступности не подтверждено общим протоколом. Выводы относятся к этому периоду и этим конфигурациям, а не ко всем нейросетям.
