# Котировки XAU/USD: происхождение и первичный аудит

## Подтверждённые параметры выгрузки

- **Дата выдачи задания:** 28 октября 2026 года.
- **Источник:** Dukascopy через [dukascopy-node](https://www.dukascopy-node.app/instrument/xauusd).
- **Инструмент:** `xauusd` (цена золота в долларах США за тройскую унцию).
- **Запрошенный диапазон:** с 28 октября 2025 года по 28 октября 2026 года; конечная граница не включена в полученный результат.
- **Наблюдаемая дата последней строки:** 27 октября 2026 года. Свеча 28 октября не включена.
- **Частота:** `d1`, **тип котировки:** `bid`, **UTC-смещение:** `0`.
- **Формат исходного файла:** `timestamp,open,high,low,close,volume`; timestamp — миллисекунды Unix.
- **Версия инструмента на момент выгрузки:** `dukascopy-node@1.51.1`.
- **Исходный CSV:** `data/raw/xauusd-d1-bid-2025-10-28-2026-10-28.csv`.
- **Команда:** см. `scripts/download_quotes.ps1`.

## Важная нерешённая особенность

**Активная UTC-календарная свеча не обязательно равна одной полной торговой сессии XAU/USD.** В текущем CSV имеется 52 воскресные свечи. Известно, что торговля золотом возобновляется в воскресенье, а границы торговых сессий могут отличаться от UTC-полуночи.

Таким образом, **312 записей нельзя автоматически объявлять 312 торговыми днями**. В частности, считать прогноз «через 5 торговых дней» простым сдвигом на 5 строк по этим данным пока нельзя без отдельного определения торговой сессии.

**До окончательного обучения моделей требуется решение по календарю:**
1. Согласовать с Алексеем Вахниным, что именно считается одним торговым днём.
2. Предпочтительно получить/сформировать свечи по границам торговой сессии Dukascopy (с учётом перехода на летнее время), чтобы соответствовать пятидневной торговой неделе.
3. Документировать фактические начало, конец и правило формирования каждой дневной свечи. Простое удаление воскресных цен без обоснования **не равнозначно** правильной пересборке сессионных свечей.
4. Только после этого создать `data/processed/` и применить индексные разбиения из `src/validation.py`.

Документация Dukascopy по сессиям: https://www.dukascopy.com/wiki/en/manuals/jforex4-desktop/trading-sessions-logic/

## Проверка своими силами

```powershell
python -m src.data_audit data/raw/xauusd-d1-bid-2025-10-28-2026-10-28.csv
python -m pytest -q
```

Модуль аудита проверяет исходные котировки **без изменения** данных и не создаёт очищенный CSV. Модуль временной валидации принимает индексный ряд уже согласованных торговых наблюдений; это не окончательный запуск эксперимента.
