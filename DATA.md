# Подготовка данных XAU/USD

В итоговом эксперименте используется **Dukascopy, XAU/USD Bid**, история за 12 месяцев на дату выдачи задания 28.10.2026. Источник и частота важны: исходный календарный D1 **не равен** восстановленной торговой сессии.

## Первичная D1-выгрузка (сохранена для истории)

Файл [data/raw/xauusd-d1-bid-2025-10-28-2026-10-28.csv](data/raw/xauusd-d1-bid-2025-10-28-2026-10-28.csv): 312 записей за период 28.10.2025–27.10.2026, включая **52 воскресных UTC-свечи**. В файле нет пустых OHLC, повторных меток и нарушений диапазонов цен. Однако пять строк такого ряда **не означают автоматически пять торговых дней**, поскольку календарные границы UTC отличаются от биржевой сессии.

Раннюю проверку можно повторить:

~~~powershell
python -m src.data_audit data/raw/xauusd-d1-bid-2025-10-28-2026-10-28.csv
~~~

**Этот D1-файл не используется как целевой ряд в финальном исследовании.**

## Итоговая сессионная выгрузка (используется в эксперименте)

Исходные [H1 Bid](data/raw/xauusd-h1-bid-2025-10-27-2026-10-28.csv) содержат **5934 часовые свечи**, на один календарный день раньше заданного периода для первой полной сессии. Экспорт получен через dukascopy-node@1.51.1, с ценами Bid, объёмами и метками UTC.

В [src/daily_sessions.py](src/daily_sessions.py) реализовано правило:
- XAU/USD: **18:00 предыдущего дня — 17:00 текущего по America/New_York**, перерыв 17:00–18:00.
- Время UTC для закрытия меняется между 21:00 и 22:00 при переходе на летнее/зимнее время.
- Для обычной сессии ожидаются 23 последовательные H1-свечи.
- Проверяются первая свеча, внутренние интервалы и OHLC; неполные внутренние часы не заполняются искусственно.
- Сокращённые сессии сохраняются с флагами; не удаляются только по причине небольшого числа свечей.

Результат: **258 торговых сессий** с **28.10.2025 по 27.10.2026**, файл [data/processed/xauusd_daily_dukascopy.csv](data/processed/xauusd_daily_dukascopy.csv). Источник, даты и девять сокращённых сессий описаны в [data/processed/xauusd_daily_audit.json](data/processed/xauusd_daily_audit.json).

Девять дат проверены по исходным H1 и праздничным уведомлениям. По пяти датам есть расхождение между **последними H1 в 15:00 NY** и **общим правилом праздничного перерыва с 13:00 NY**. Не установлено, были ли дополнительные котировки доступны для торговли. Цены оставлены без изменений, а влияние альтернативного времени закрытия исследовано отдельно в [HOLIDAY_SESSION_AUDIT.md](HOLIDAY_SESSION_AUDIT.md). Запрос Dukascopy не отправлялся: для учебной работы ограничение раскрыто явно.

## Признаки и горизонты

В [src/daily_features.py](src/daily_features.py) формируются 10 признаков, доступных в момент окончания торговой сессии: цена Close, лаги Close, доходности, диапазон дневных цен, скользящая средняя и волатильность, день недели. Цели **Close[t+1] и Close[t+5]** рассчитываются по исходной последовательности сессий **до отбора строк**. Никаких случайных перемешиваний или обучений преобразований на тесте.

В [data/processed/xauusd_daily_model_ready.csv](data/processed/xauusd_daily_model_ready.csv) — **196 обучающих** и **47 тестовых** исходных дат. Первая тестовая дата — 17.08.2026, последняя — 20.10.2026; пятую будущую цель последнего прогноза наблюдаем 27.10.2026.

Алексей также подготовил CSV с **168 исходными столбцами** внешних показателей. Они сохранены в [data/external/](data/external/README.md) без изменения исходных значений, рядом находится реестр пропусков. В основной работе они не применялись, так как момент исторической доступности ряда признаков и возможные пересмотры данных не подтверждены. HistData и Dukascopy не смешиваются как два источника целевого Close.

## Как воспроизвести

Из корня репозитория, после установки [requirements-mlp.txt](requirements-mlp.txt):

~~~powershell
python run_daily_baseline.py
python -m pytest -q
~~~

Скрипт пересоздаёт сессионный CSV, готовую таблицу, Naive и JSON-аудит из уже сохранённой H1-выгрузки. Для повторного скачивания H1 предусмотрен [scripts/download_quotes_h1.ps1](scripts/download_quotes_h1.ps1); при работе с сохранённым CSV интернет не нужен.
