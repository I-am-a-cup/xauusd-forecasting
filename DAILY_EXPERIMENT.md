# Дневные данные Dukascopy и первый результат Naive

Это воспроизводимый вариант подготовки золота по требованиям практик 8–9. Он не заменяет автоматически датасет Алексея Вахнина: у того больше внешних признаков и другой источник золота (HistData). Здесь используется только Dukascopy.

## Данные

Дата выдачи — 28 октября 2026 года. Берём 12 месяцев истории; для первой полноценной сессии скачиваем один предыдущий календарный день.

- Источник: Dukascopy XAU/USD, H1, Bid, с объёмами, UTC; утилита dukascopy-node@1.51.1.
- Часовая выгрузка: data/raw/xauusd-h1-bid-2025-10-27-2026-10-28.csv — 5 934 свечи.
- Дневной ряд: data/processed/xauusd_daily_dukascopy.csv — 258 сессий, 28.10.2025–27.10.2026.
- Торговые сутки золота: 18:00–17:00 по Нью-Йорку, с перерывом 17:00–18:00. Часовая метка обозначает начало H1, конец получается прибавлением одного часа.
- Обычная сессия содержит 23 последовательные часовые свечи. Внутренние пропуски и отсутствие начала сессии не допускаются.
- 9 сокращённых сессий с 19–21 свечой сохранены с явными отметками в data/processed/xauusd_daily_audit.json. Точные праздничные часы этих дней ещё надо подтвердить по календарю торговли.
- Данные с HistData и Dukascopy не смешиваются.

Официальные сведения: https://www.dukascopy.com/wiki/en/manuals/jforex4-desktop/trading-sessions/ и https://www.dukascopy.com/wiki/en/manuals/jforex4-desktop/trading-sessions-logic/.

## Признаки и проверка

Создано 10 простых признаков из истории самого золота: текущая цена закрытия, лаги, доходности, дневной размах, скользящее среднее, волатильность и день недели. Признаки не используют будущую цену. Из-за отсутствующих зарубежных индексов торговые даты не удаляются.

- Для итогового теста выделены последние 20% сессий. Общие даты формирования прогнозов на 1 и 5 торговых дней — 47 наблюдений.
- Для будущих обучаемых моделей получены 196 обучающих и 47 тестовых строк. Обучающие целевые значения не пересекают границу начала теста.
- На истории до теста доступны 4 расширяющихся окна временной валидации.
- Подготовленный набор признаков и целей: data/processed/xauusd_daily_model_ready.csv.

## Измеренные результаты Naive

В обоих горизонтах прогноз равен последней известной цене закрытия:

| Горизонт | Прогнозов | MAE | RMSE | sMAPE |
|---|---:|---:|---:|---:|
| 1 торговый день | 47 | 47,57 | 63,75 | 1,10% |
| 5 торговых дней | 47 | 93,96 | 123,08 | 2,16% |

MAE и RMSE — в долларах США за тройскую унцию. Точность направления равна 0% по определению наивной модели (прогноз изменения — ноль; реальные изменения были ненулевыми). По этой метрике нельзя делать вывод о плохой пригодности Naive: основная метрика сравнения — MAE.

Точные прогнозы и метрики: results/predictions/naive_daily.csv и results/metrics/naive_daily.csv. Результатов ARIMA, Random Forest или MLP пока нет. Проверка сокращённых сессий может изменить итоговые значения.

## Повторный запуск (Windows PowerShell)

    python -m pip install -r requirements-verified.txt
    ./scripts/download_quotes_h1.ps1
    python -m pytest -q
    python run_daily_baseline.py

Если исходный H1 CSV уже находится в репозитории, достаточно последней команды. Скрипт создаёт дневные CSV, прогнозы, метрики и JSON-отчёт заново, не затрагивая файлы Алексея.

Проверено на Python 3.10.11. Точные версии пакетов указаны в requirements-verified.txt.

## Что ещё не готово

Нужно подтвердить девять сокращённых сессий по расписанию, согласовать основной источник данных (по методичке Dukascopy), реализовать остальные модели и сравнить их на тех же тестовых датах. Дополнительные признаки Алексея требуют отдельной проверки времени публикации и обработки отсутствующих значений.

Отдельные MAE из HistData и Dukascopy нельзя сравнивать как непосредственное соревнование моделей: у поставщиков могут отличаться цены.
